# Stone-BIM/.github

Служебный репозиторий организации [Stone.BIM](https://github.com/Stone-BIM).

- `profile/README.md` — то, что показывается на странице организации.
- `CONTRIBUTING.md`, `SECURITY.md`, `SUPPORT.md`, `CODE_OF_CONDUCT.md`, `PULL_REQUEST_TEMPLATE.md` — правила по умолчанию для всех репозиториев организации, у которых нет своих файлов.
- `.github/ISSUE_TEMPLATE/` — шаблоны issue по умолчанию.

Репозиторий должен оставаться публичным: GitHub показывает профиль и общие файлы только из публичного `.github`.
