# Stone.BIM

Автоматизация BIM: инструменты, которые снимают рутину с проектировщиков и аналитиков.

## Направления

- **Stone.Revit** — единый Revit add-in с модулями параметров, спецификаций, проверок модели, поиска дубликатов и назначения кодов классификатора. Revit 2022–2027, .NET, WPF.
- **Бюджетные объёмы** — расчёт объёмов и стоимости по моделям: локальный сервер, общие данные в сети, Viewer моделей.

## Стек

`C#` · `.NET` · `WPF` · Autodesk Revit API (Nice3point.Revit) · `Python` · `JavaScript` · Inno Setup

## Доступ

Репозитории приватные и доступны участникам организации по приглашению. Установщики и заметки к выпускам — во вкладке Releases соответствующего репозитория.
